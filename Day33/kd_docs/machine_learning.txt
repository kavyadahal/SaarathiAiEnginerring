Machine learning is a branch of artificial intelligence that enables
computers to learn patterns from data instead of relying entirely on
explicitly programmed rules. Machine learning systems use algorithms
to identify relationships in training data and use those relationships
to make predictions on new examples.

Supervised learning uses labeled training data. Each training example
contains input features and a known target. Classification predicts
categories, such as whether an email is spam. Regression predicts
continuous values, such as house prices.

Unsupervised learning works with data that does not have labeled
targets. Clustering groups similar observations, while dimensionality
reduction represents data using fewer features. These techniques can
help discover patterns in large datasets.

A learning rate is a hyperparameter that controls the step size used
when updating model parameters during optimization. A learning rate
that is too high can cause the optimization process to overshoot a
minimum. A learning rate that is too low can make training very slow.

Model evaluation measures how well a trained model performs on data
that was not used to fit its parameters. The train-test split helps
estimate performance on unseen examples. The choice of evaluation
metric depends on the problem and the cost of different errors.
